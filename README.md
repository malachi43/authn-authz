# Spring Security: Authentication & Authorization

This repository demonstrates how authentication and authorization work in Spring Security.

**Authentication** verifies who a user is, while **authorization** determines what an authenticated user is allowed to access.

The project explores how Spring Security secures applications by handling user authentication, managing roles and authorities, and restricting access to protected endpoints based on permissions.

## Key Concepts
- **Authentication:** Verifying user identity.
- **Authorization:** Controlling access to resources.
- **Roles and Authorities:** Defining what users can access.
- **Security Configuration:** Configuring access rules and protecting endpoints.

The goal is to build a practical understanding of Spring Security and how to implement secure, role-based access control in Spring Boot applications.
